# Milena Montenegro — Portfólio estático

Projeto feito somente com:
- HTML5
- CSS3
- JavaScript puro (Vanilla JS)

Não utiliza React, frameworks, backend, banco de dados, login ou painel administrativo.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta.
3. Dê dois cliques em `index.html` ou abra-o pelo navegador.

Também pode usar a extensão Live Server do VS Code para visualizar atualizações automaticamente.

## Como personalizar
Edite `js/data.js`:
- apresentação, biografia e e-mail;
- links de LinkedIn, GitHub e Instagram;
- áreas de atuação;
- experiências de ensino;
- projetos e tecnologias.

Edite `css/style.css` para alterar cores, tipografia, espaçamentos e layout.

Edite `index.html` para mudar a estrutura das seções.

## Formulário de contato
O formulário valida os campos no navegador e abre o aplicativo de e-mail por meio de `mailto`. Não armazena nem envia dados para um servidor. Configure o e-mail real em `js/data.js`.

## Publicação
Como é um site estático, pode ser hospedado em GitHub Pages, Netlify, Vercel ou hospedagem tradicional, sem servidor próprio.
